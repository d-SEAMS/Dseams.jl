API

Dseams has two layers:

  1. Frame-level analysis functions (read_frame, chill_plus, primitive_rings, cages, steinhardt, q4_q6, symmetry, jump_tau90) that operate on trajectory frames.
  2. Re-exported seams_* wrappers for lower-level tasks that map closely to the C ABI.

Common starting points:

  • read_frame(path; kwargs...) to load one frame.
  • nframes(path) to inspect trajectory length before analysis.
  • features(), has_chemfiles(), and has_readcon() to check which optional trajectory readers (chemfiles for PDB/GRO/DCD/CIF, readcon-core for .con) the loaded engine supports.
  • Dseams.example_path(name) for bundled demonstration trajectories.

The full exported API is listed below.

Dseams.Dseams — Module
Dseams

Julia front for the d-SEAMS engine. Calls libseams_lang with ccall.

The library comes from libseams_jll. A local build is used instead when the SEAMS_LANG_LIB environment variable or the libseams_lang preference names it; see Dseams.set_library!.

CxxWrap is not required. Ice Ih (data/ice1h.lammpstrj, every atom) is 128 hexagonal waters and 256 primitive six-rings.

The C API names re-exported here call libseams (SEAMS_LIB, else the loader path) and are System, seamssystemcount, seamssystemread, seamschill, seamssteinhardt, seamscages, seamssignaturecages, seamsneighboursknn, seamsrdf, seamsrunningcn, seamscoordination, seamshbonds, seamsdensityaxis, seamsfingerprint, seamscontactpairs, seamsdomains, seamsprisms, seamsmonolayer, seamsringsvertices, seamssitetable, SeamsError, ChillPlus, RingHistogram, CageScore, SteinhardtOrder, SignatureCages, and Q4Q6.

Dseams.cages — Method
cages(frame; cutoff=3.5, type=0, k=4, graph="seeded")

Hexagonal and double-diamond membership. cage is 0 water, 1 hexagonal only, 2 double-diamond only, 3 both. The four counts are disjoint and match seams cages. cutoff is angstrom. A frame with no atoms gives an empty cage and four zero counts.

Dseams.chill_plus — Method
chill_plus(frame; cutoff = 3.5, type = 0, graph = "cutoff")

CHILL+ labels. graph = "cutoff" (the default) bonds every pair closer than cutoff. graph = "mutual" bonds the mutual four nearest neighbours; cutoff + 1.5 only sizes the search cells and does not bound a bond, so an atom with no neighbour within cutoff can still be bonded. A frame with no atoms gives empty labels and names and nine zero counts.

Dseams.read_frame — Method
read_frame(path; frame=1, type=0)

Read one frame. Native LAMMPS trajectory dumps and XYZ files are always supported; PDB, GRO, DCD, and CIF require has_chemfiles, and .con files require has_readcon. frame is 1-based. type = 0 guesses oxygen. A positive type keeps that species. A negative type keeps every atom.

A frame that holds no atoms, or none of the kept type, is a valid frame with nop(frame) == 0, and every analysis accepts it. A frame below 1, or past the last one in the file, throws SeamsError; neither gives an empty frame.

Use the libseams_lang at path (for instance build/bindings of a seams-core checkout) instead of the one in libseams_jll, or go back to the JLL with nothing. Stored in LocalPreferences.toml of the active project; restart Julia to take effect.

Dseams.steinhardt — Method
steinhardt(frame, order_l; cutoff=3.5, type=0, graph=nothing)

Local Steinhardt parameter. order_l is 3, 4, 6, 8, or 12, and any other degree throws SeamsError. Omitting graph uses the cutoff shell. "mutual" is the four nearest neighbours, not bounded by cutoff. An atom with an empty shell has ql and qlbar equal to 0, and a frame with no atoms gives empty vectors.

source
Dseams.symmetry — Method
symmetry(frame; shell_rmsd=0.12)

Per-atom shell label. 0 is ice Ih, 1 is ice Ic, 2 is stacking disorder, and -1 is anything else, which includes an atom with no neighbours. A frame with no atoms gives an empty vector.
