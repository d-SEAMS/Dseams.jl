Dseams

Dseams.jl is a Julia front for the d-SEAMS engine. It reads LAMMPS trajectories and XYZ files (plus PDB, GRO, and .con when the engine includes chemfiles and readcon-core) and exposes the same core analyses: CHILL+, primitive rings, cage census, Steinhardt order, shell symmetry, and jump reorientation times.

using Dseams
f = read_frame(Dseams.ice_ih_path(); type = -1)
chill_plus(f; graph = "cutoff").counts["hexagonal"]       # 128
primitive_rings(f; graph = "cutoff", max_depth = 6)[6]    # 256

The Julia chapter of the d-SEAMS book covers the same interface, and a video walk-through shows a full session.

The engine library

libseams_jll provides the engine for Linux (glibc and musl; x8664, aarch64, powerpc64le, riscv64) and macOS once the recipe, pinned to seams-core commit c1efa8c, is merged into Yggdrasil. `dev/developjll.jldevelops a stand-inlibseamsjllwith no binaries, and the engine is a local build of [seams-core](https://github.com/d-SEAMS/seams-core). To use one, name itslibseamslang`:

Dseams.set_library!("/path/to/seams-core/bbdir/bindings/libseams_lang.so")
# restart Julia; Dseams.set_library!(nothing) goes back to the JLL

This writes the libseams_lang preference to LocalPreferences.toml. The SEAMS_LANG_LIB environment variable takes precedence over the preference. With either one set, libseams_jll is not loaded.

To replace the whole JLL artifact with an install prefix instead, use an Overrides.toml in ~/.julia/artifacts, as for any JLL.

Data used in examples

Dseams.example_path(name) resolves the trajectories bundled in data/: ice1h.lammpstrj (ice Ih, 128 oxygens), exampleTraj.lammpstrj (a TIP4P/ice frame) and nucleation_f1.lammpstrj (one frame of an mW nucleation run). The .source.txt files there record where they came from.
